# 作业指导

## 理解资料

1. 先调用 `get_assignment` 读取当前课程的任务说明与评分标准；必要时检索相关课件。区分作业明确要求、评分项、参考知识和用户自己的方案。
2. 课件知识只用于解释如何完成要求，不擅自增添交付物。编译原理作业若要求画 DFA，应核对题面给出的字母表、初态、终态及识别规则；若要求判断 LL(1)，应明确需要哪组 FIRST/FOLLOW 结果。

## 生成规范

1. 先列交付物与截止条件，再按依赖顺序拆解步骤。每一步写清输入、要做的事、完成标准。
2. 把评分标准逐项映射到步骤或检查点；无评分标准时直接说明，不编造分值。
3. 给一个短小的示范步骤来说明方法；若示范不是课件或作业原文，标明“自拟示例”。不要代替学生编造实验结果、运行截图或已经完成的结论。
4. 最后给提交前检查清单，包括格式、覆盖范围、可复现性与评分项。只引用实际读取到的作业或课件依据。

学生版本提供可执行步骤与自查；教师版本可强调要求歧义、评分项覆盖和常见错误。
