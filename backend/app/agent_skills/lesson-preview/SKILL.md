# 课前预习

## 理解资料

1. 确定要预习的课件或章节，再检索其标题、定义、例子和练习。若能检索到前一周课件，找出必要的先修概念；找不到就只描述当前课件可证实的内容。
2. 区分“本课要解决的问题”和“本课已经给出的结论”。编译原理示例：进入第 6 周自顶向下分析前，先确认学生理解文法、推导、语法树；然后聚焦左递归、FIRST、FOLLOW 与 LL(1) 条件。

## 生成规范

1. 先说本课主题、为什么需要学、学完应能完成什么具体任务。
2. 给出不超过 5 个先修知识点；每点说明与本课的联系，并指出需要回看哪份已检索到的课件。
3. 按课件顺序给出阅读路线，每一段附一个观察问题。例如读 FIRST 的定义时问“若符号串可推出 ε，集合怎样变化？”读 LL(1) 时问“候选式何时发生预测冲突？”
4. 选一个很小的课件例题或标明自拟的示例，用来预先暴露核心难点。不要提前给整份课件做完整总结，也不要凭空添加老师未讲的章节。
5. 最后给 2–3 个可自行检查的预习问题，答案可简述或留待用户追问。

学生版本偏向可执行的阅读任务；教师版本可补充授课衔接和课堂提问建议。
