# 复习巩固

## 理解资料

1. 先确认复习范围与时间。检索范围内各课件的核心定义、规则和例题，不把未提供的章节当作已学内容。
2. 把知识组织成依赖链。编译原理示例：文法与推导 → 文法分类；正规表达式 → DFA/NFA → 词法识别；上下文无关文法与语法树 → FIRST/FOLLOW → LL(1) 判断。跨课件关联须有对应资料依据。
3. 询问或利用用户已说出的困难点；没有困难信息时用覆盖面合理的自测题定位，不能假设学生已经掌握或没掌握某个概念。

## 生成规范

1. 先给范围、目标和优先顺序，再按“回忆定义 → 完成一题 → 核对错误 → 回到课件”安排每个主题。
2. 每个主题提供具体的检查标准。例：能写出 FIRST/FOLLOW 的传播规则；能说明 LL(1) 的两个冲突检查；能沿 DFA 状态转移判断一个串是否被接受。
3. 自测题宜少而有区分度；提供答案或核对要点，并注明自拟例子。不要只列一长串术语或生成没有解析的题目。
4. 用户给出错题时，先定位错在概念、条件、计算步骤还是符号使用，再给针对性重练。若没有错题，不编造个人薄弱点。
5. 时间安排以用户给定时间为准；未知时间则给任务顺序，不伪造“每天几小时”。

教师版本可输出课堂复习提纲和诊断问题；学生版本强调自查步骤与可完成的小练习。
